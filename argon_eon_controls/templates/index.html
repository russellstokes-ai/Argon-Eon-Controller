Disk monitoring

Five-minute checks. Sleeping disks remain asleep. Dashboard refresh reads cached data only. Argon EON bays are detected and monitored automatically (SAT). Other USB bridges are not probed until you select a verified SATA passthrough type. Unsupported power checks stop further probing.

Optional health tests

Run once per calendar week/month when each configured disk is naturally awake. Sleeping disks are deferred. Long tests can increase disk load.
